# 客户端接入与设置

适用 1.0.0 客户端。接入协议见[简单接入](simple-onboarding.md)，实现说明见[实现概览](implementation.md)。

## 添加服务器

设置 → 添加服务器 → 填写 HTTP 或 HTTPS 地址和“此设备的名称” → 添加并连接。名称用于 Web 辨认；服务器显示名可不填，连接后读取服务端名称。App 保存独立凭据，网络失败保留地址并允许重试，不要求 Web 登录或配对码。支持多服务器并存，来源筛选不暂停其他来源。

设备详情可复制消息发送地址。功能卡片在 Web 工作台创建数据源、设计和发布，上报地址从 Web 复制，再在客户端导入订阅码。旧设备数据地址及发送 Key 保留在“兼容接口与高级信息”，服务已有本机数据卡片。

## 创建卡片

客户端“＋”提供最新消息、消息摘要和最近消息列表，每张选择一个已连接服务器。本机模板读取该来源的真实消息历史，不绑定业务字段或伪造行情。

行情、服务器状态、进度等功能卡片统一在 Web 设计，通过订阅码/链接导入，客户端可改名、调整外观与允许的叶组件参数。已有本机功能卡片兼容保留。取消不创建，保存后再在系统小组件中选择；多个同尺寸组件可组成系统智能叠放。

首页用户卡片在前，“示例”默认收起，展开可查看最新消息、AAPL 非实时行情与任务进度。示例只展示效果，不自动创建用户业务数据、连接或已保存卡片。

## 设置与数据

- 服务器：名称、设备名称、启停、同步、复制地址与移除；修改名称保留绑定和已有数据。
- 通知：授权状态、推送连接、请求权限及系统设置入口。
- 数据与同步：按来源查看数量并主动同步。
- 语言：跟随系统、中文、English。App 与 Widget 共享偏好，用户卡片名称与消息内容不翻译。
- 外观：系统、浅色、深色。
- 本地数据管理：按来源清理本机消息，保留服务器历史、快照和卡片。
- 关于：官网与 GitHub 的可点击图标链接，提供服务端部署与更多详情入口；版本动态读取。
- 数据与隐私：说明服务器同步、本机保存、连接标识和删除范围；版本从应用 Bundle 读取。

停用先请求服务端暂停；移除先请求撤销，失败不伪称成功。更多数据处理说明见[数据与隐私](privacy-data-flow.md)。

## 行为与边界

点击系统消息通知后，App 按本机已绑定的服务器、账号、设备及消息 ID 直接打开详情；冷启动时保留跳转请求，返回后回到消息列表。已移除/停用/歧义来源不会凭通知重新创建连接。HTTP 连接允许 IP 及自定义端口；HTTPS 继续验证系统信任的证书，不绕过 TLS 验证。

移除流程保留先远端解绑、成功后清理所选本机来源。请求超时、530、服务停用或其他解绑失败时，显示“远端解绑未完成”，提供重试、取消及“强制删除本地配置”。未选择强制删除前，连接、消息、卡片、缓存和凭据保留；强制删除只清理该来源，不承诺远端绑定或系统通知已经停止。桌面小组件刷新时间受 iOS 系统调度影响，不保证固定每分钟刷新。
