# 多服务器与来源隔离

同一个 App 可以添加多台 Vao Push 服务器。每台服务器都有独立连接、设备凭证、消息历史、数据源和卡片订阅；筛选一个来源不会停止其他来源的接收。

## 连接与凭证

App 保存服务器地址和设备凭证，服务器保存凭证摘要及可恢复注册结果。设备名称仅用于识别，不作为身份凭证。发送 Key、消息读取凭证和 Widget 读取凭证作用不同，服务端会在每次请求时检查设备归属、资源关系和撤销状态。

## APNs

自建服务器直接向 Apple APNs 发送，不经过 Vao Push 中央网关。正式安装包会在安装阶段写入固定 App 标识对应的推送身份；用户只需在官方 App 中填写自己的服务器地址。开发或生产私钥不进入公开源码、Web 页面或示例文件。

## HTTPS

服务器地址可以是 IP 加端口，也可以是域名和 HTTPS 反向代理。App 按协议、主机、端口和路径隔离连接凭证，不会把一个服务器的凭证借给其他来源。
