# Vao Push Web 控制台

Vue 3 / TypeScript / Vite，使用 Vao 蓝灰视觉与 A 版消息 Logo，当前为服务器管理员控制台，包含手动消息、卡片数据、卡片工作台、接入设备、发送记录和服务器设置。手机填地址自动注册；Web可多选、全选/清空，临时手动发送，或保存为默认接收列表并复制统一自动消息地址。手动选择不改默认列表。右上角可切换中文/English，以及浅色、深色或跟随系统，选择保存在本浏览器；窄屏时导航改为横向滚动。

使用 Node 20.19+ 或 22.12+：

```sh
npm ci
npm test
npm run build
```

将 dist 作为服务端 web_dir，由同一 HTTPS 入口提供页面与 /v1 API。无需跨域授权。开发模式的 Vite 代理指向本机后端；需要将测试后端 public_url 配成实际浏览器 origin，并使用本机受信任 HTTPS，保持安全 Cookie 与来源校验，不关闭 CSRF 来绕过开发配置。

发送按钮在提交期间禁用，并对未确认完成的同一逻辑请求复用幂等键。数据编辑携带读取到的 ETag；版本冲突时保留草稿并提示重读。HTTP 代理必须保留快照的 no-transform，避免压缩改变强 ETag。

默认接收列表使用独立revision作条件更新；Web从响应正文构造源站If-Match，避免代理压缩弱化ETag导致误判冲突。列表刷新不擅自扩大用户当前的手动选择；已失效的选中项可取消，服务端对无效手动列表整次拒绝。

卡片工作台支持10类原生组件的可视化/JSON编辑、多尺寸预览、AI生成说明、草稿/发布和订阅码。手机导入完整设计后可独立微调，Web更新保留本机调整。数据源支持外部上报、手动JSON或公网HTTPS GET JSON采集与字段映射，不内置价格阈值。原有设备数据入口保留字段表单与JSON编辑；首次合法写入自动创建数据ID。接口、限制及验收边界见[工作台说明](../docs/card-studio-api.md)。

工作台默认显示“我的卡片”，含搜索、草稿/发布状态、来源预览、编辑及接入订阅管理。新建向导按数据来源、设计和发布分步；正常编辑用字段选择，组件树/布局属性为高级入口。AI页展示完整输入、排版要求、有效输出和预览，并提供说明复制/结果校验流程。设计使用的sourceID与数据源管理选择分开，切换未保存设计可保存或放弃。辅助逻辑及格式化测试由npm test执行，详见[入门指引](../docs/web-studio-guide.md)。

设备显示客户端填写的名称，列表同时展示标识；即使重名也可区分。名称变更不修改接收列表。
