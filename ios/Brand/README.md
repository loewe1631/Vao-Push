# Vao Push 品牌资源

本目录包含 Vao Push 的品牌标记、App 图标和界面使用说明。Vao Push 沿用 Vao 品牌的 V 字轮廓与蓝灰色基础，同时增加消息气泡和提示点作为产品识别。

- `vao-push.svg`：矢量品牌标记；
- AppIcon：iOS 1024 × 1024 不透明图标；
- BrandMark：App 内品牌标记；
- GitHub 图标：来自 Simple Icons，来源和 CC0 许可见 [THIRD_PARTY.md](../../THIRD_PARTY.md)。

品牌颜色和布局参数仅作为产品视觉参考，桌面卡片允许用户按自己的数据和主题设计。
